#Análisis de precios del catálogo de BMW para 2026
El repositorio contiene un proyecto de análisis de datos con el enfoque puesto en las tendencias, mercado y precios de los modelos de la gama de BMW para el 2026. 
Tiene el objetivo de identificar patrones como la depreciación, facvtores que influyen en el coste, y visualizaciones estadísticas. 

#Estructura:
Notebook principal que incluye:
- Importación y limpieza de datos en conjunto
- Análisis exploratorio de datos (EDA)
- Gráficas de distribución y correlación de precios

#Tecnologías utilizadas
- Lenguaje: Python 3.12
- Librerías: Pandas, NumPy, Matplotlib, Seaborn, Plotly

#Forma de ejecutar el proyecto: 
  1. Clona este repositorio:
   ```bash
   git clone https://github.com/adrianamorchons/analisis_precios_bmw_2026.git
   ```
  2. Asegúrate de tener instalado Jupyter Notebook o la extensión de Jupyter en Visual Studio Code.
  3. Abre el archivo `ANALISIS_BMW_PRECIOS_2026.ipynb` y ejecuta las celdas.
